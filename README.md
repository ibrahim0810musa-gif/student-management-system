# Student Management System

A web-based Student Management System built with HTML, CSS, and JavaScript. This application provides an interface for managing student records, organizing classes, and viewing student statistics.

## Features

- **Dashboard:** Displays student statistics, including total students, active students, inactive students, and total classes.
- **Student Management:** Register, search, edit, and delete student records.
- **Student Validation:** Validates student information and prevents duplicate email addresses.
- **Class Management:** Organizes students into different classes with class capacity limits.
- **Student Status:** Manage active and inactive student records.
- **Search Functionality:** Quickly find registered students.
- **Confirmation Dialog:** Displays a confirmation before deleting student records.
- **Notifications:** Provides feedback for successful and unsuccessful actions.
- **Sidebar Navigation:** Responsive navigation menu for accessing different sections.
- **Dark Mode:** Allows users to switch between light and dark appearances.
- **Settings:** Provides application preferences and record management options.
- **Contact Page:** Includes a contact form with input validation.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Structure

- `index.html` – Dashboard page.
- `students.html` – Student registration and management.
- `classes.html` – Class information and organization.
- `about.html` – About the application.
- `contact.html` – Contact form.
- `settings.html` – Application settings.
- `style.css` – Application styling and responsive layout.
- `script.js` – Application functionality and interactions.

## How to Use

1. Open the application in your web browser.
2. Navigate through the sidebar menu.
3. Open the Students section to register new students.
4. Enter the student's details and select a class.
5. Search, edit, or delete student records.
6. Visit the Classes section to view available classes.
7. Explore the Settings section to manage application preferences.

## Data Storage

The application uses the browser's Local Storage to save student records and application data.

This allows saved records to remain available in the same browser after refreshing the page.

Session Storage is also used for sidebar state management.
